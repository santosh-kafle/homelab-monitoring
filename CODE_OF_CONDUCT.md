# Code of Conduct

This project is for people learning, so everyone is a beginner at something here. Be
kind, be patient, and assume people mean well.

- **Do:** explain things, ask questions, say when you don't know, give feedback on the
  work and not the person.
- **Don't:** insult, harass, mock someone's question or skill level, or post other
  people's private information.

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, discussions and anywhere else you represent the
project.

## Reporting

If someone's behaviour bothers you, contact the maintainer privately through the email
on [their GitHub profile](https://github.com/santosh-kafle). Reports are kept
confidential. The maintainer may remove comments, lock threads or ban people who don't
follow this code.
